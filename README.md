# TSMIS Project Inspector

A small, portable Windows app that lists saved TSMIS/TSNR versions, environments,
and service names in ArcGIS Pro projects without changing them.

[**Download for Windows**](https://github.com/yunusshaikh7/TSMIS-Project-Inspector/releases/latest)

1. Extract the ZIP to a writable folder.
2. Open **TSMIS Project Inspector.exe**, choose a project folder, and click **Scan**.
3. Use **Refresh**, **Clear**, or **Export** to manage your results.

Requires **Windows 10/11 (64-bit)**, installed and licensed **ArcGIS Pro**, and
**Microsoft Edge WebView2 Runtime**.

Settings and saved lists stay in **Data** beside the app. Updates are under
**Settings > Check for updates**. Give coworkers a fresh release ZIP; your used
app folder contains saved work metadata.
