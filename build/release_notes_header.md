Portable Windows app that lists the TSMIS branch version each ArcGIS Pro
project (.aprx) uses — no ArcGIS Pro or arcpy needed (see `Start Here.txt`
inside the zip).

Download `…-win64.zip`, unzip it anywhere writable, and double-click
`TSMIS Branch Identifier.exe`. If Windows warns about an unknown publisher,
choose **More info → Run anyway** (in-house unsigned tool). Right-click the
downloaded zip → Properties → **Unblock** before extracting.
