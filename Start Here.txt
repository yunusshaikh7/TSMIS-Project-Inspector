TSMIS Branch Identifier 0.2.1

1. Right-click the downloaded ZIP and choose Extract All.
2. Keep the whole extracted folder together. Open TSMIS Branch Identifier.exe.
3. Choose your ArcGIS project folder, then click Scan.
4. Click a project for its layers. Export saves results for Excel.

Portable: settings and updates stay in the Data folder beside the app.
Copy the whole app folder to move it. Use a folder you can write to;
no installation, administrator access, or separate Python is needed.
Temporary browser and scan files are cleaned up after use.

The work PC needs licensed ArcGIS Pro and Windows 10/11 (64-bit).
Microsoft Edge WebView2 is normally already installed. If it is missing,
the app will explain what IT needs to install or repair.

If ArcGIS is not detected, choose its Python in Settings. Open ArcGIS Pro
and sign in first if scanning fails. Save open projects before scanning;
OneDrive files must be available locally. Projects are never changed.

First work-PC test: Settings -> Test / diagnostics -> Run diagnostic scan.
Afterward, Save diagnostic ZIP. It contains connection metadata and local
paths, not project files, feature data, or credentials.

Updates: Settings -> Check for updates. Download, then Open updated app.
The new copy includes your settings. Use that new folder's app next time.
Older copies remain available until you remove them.
